### 19. Round 6：修复右上角动图「图形显示失败」（真因找到）
用户报"图形显示失败"，截图显示右上角圆形头像里是**碎图标**（视频加载失败的占位）。

**根因**：`backend/main.py` 原先用 `app.mount("/", StaticFiles(...))`。
Starlette 的 `StaticFiles` 在 Windows 上按 RFC 3986 解码路径，对
`生成可爱动态图 (2).mp4`（**中文 + 空格 + 半角括号**）在 percent-encoding
往返时校验不一致，返回 **400/404** → `<video>` 触发 error → 显示碎图标。
（`curl` 实测：编码后路径 400，说明当时连编码形式都过不去。）

**修复（后端 `main.py` 第 415 行起）**：把 `StaticFiles` 换成自定义兜底路由
`@app.get("/{full_path:path}")` → `_serve_frontend()`：
1. `unquote()` 解码原始 URL → `rel`；空路径或 `/` 结尾补 `index.html`；
2. `os.path.abspath` + `startswith(root)` **防目录穿越**；
3. 精确命中 → `FileResponse`（自带 **Range 支持**，视频可拖进度/循环）；
4. 未命中 → 按 **NFC 规范化**文件名在父目录里模糊匹配（兼容 NFD 文件名）；
5. 都没有 → 404。
- 同时 `from fastapi import ... Request` 补上 import；`import unicodedata`。
- ⚠️ **必须放在所有 API 路由之后**（文件末尾），否则会吞掉 `/api/*`。

**修复（前端 `index.html`）**：两个 `<video>` 加**双写法自动重试**：
- `onerror="retryVideoSource(this)"` + `data-alt-src`（未编码）+ `data-encoded-src`（编码）；
- `retryVideoSource()` 用 `decodeURIComponent(cur)` 与 `alt` 比较，切到另一种写法并 `load()`；
- `dataset.retried` 防死循环。

### 22. Round 9：AI 回复的多余空行
用户："AI回复总是空一行，不需要"。

**根因**：AI 返回的每段之间都带 `\n\n`（甚至 `\n\n\n`），
而 `.chat-bubble` 是 `white-space: pre-wrap` + JS 用 `textContent` 写入，
所有换行都被原样渲染 → 视觉上出现大片空行。
实测样本：welcome_message = `'\n欢迎，侦探。\n\n我将为你主持一场推理游戏。\n\n...\n'`。

**修复（前端 `index.html`，渲染层压平，不改 AI 输出）**：
新增 `collapseBlankLines(text)`：
```js
String(text)
  .replace(/\r\n?/g, '\n')      // 统一换行符
  .replace(/[ \t]+\n/g, '\n')   // 去行尾空格
  .replace(/\n{2,}/g, '\n')     // 连续空行 → 单个换行
  .replace(/^\n+|\n+$/g, '');   // 去首尾空行
```
接入 **两处**（缺一不可）：
1. `addInquiryToHistory()`：`bubble.textContent = collapseBlankLines(content)`（历史重放）；
2. `addTypingBubble()` 的 `render()`：`bubble.textContent = collapseBlankLines(text)`
   （流式打字过程，否则打字时会先撑出空白再回缩）。

**未改动**：`#caseBackground` / `#sceneDescription`（`.section-content`）没有 `pre-wrap`，
HTML 天然折叠空白，无需处理；`.bonus-item` 与通知条虽是 `pre-wrap` 但都是单行短文本，保持原样。

**验证**：
- 纯函数用例全通过：`'\nA\n\nB\n'`→`'A\nB'`；`'A\n\n\n\nB'`→`'A\nB'`；`'A   \nB'`→`'A\nB'`；
  `'A\r\n\r\nB'`→`'A\nB'`；`'A\nB'` 不变；`''`→`''`。
- 浏览器实测：11 个换行（含 4 组空行）的样本 → DOM 文本 5 个单换行、`hasBlankLine:false`，
  截图确认段落之间只剩普通换行、无空白行。
- 备份：`frontend/index.html.bak-r9-20260914-211140`。
